# ascend-legal

Política de Privacidade do app Ascend, publicada pelo GitHub Pages em
https://davisamasoa.github.io/ascend-legal/ (o app e a Play Store apontam
para esse endereço; o link de exclusão de conta usa `#apagar-conta` — não
renomear essa âncora).

- `index.html` — a página inteira (estilos dentro do arquivo).
- `fonts/` — fontes do app, servidas daqui (sem Google Fonts).
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` — o logo do Ascend.

Ao mudar o texto: atualizar a data "Última atualização" e, se a mudança
exigir novo aceite no app, `PRIVACY_VERSION` em
`ascend-app/src/constants/legal.ts`. Esta é a versão oficial da política
(a de `ascend-app/docs/privacy/` é só um rascunho antigo).
